# Режим бога

[English version](god-mode.md)

Чтобы включить режим бога для текущего запуска, добавьте параметр `--god`:

```text
openxcom.exe --accessibility --god -playIntro false
```

При создании новой кампании количество денег устанавливается в максимальное
64-разрядное знаковое значение. В уже существующих сохранениях количество
денег не изменяется.

В тактическом бою обычные солдаты XCOM не получают урон здоровью, оглушение,
повреждения брони, урон от огня и смертельных ран и не могут быть оглушены
падением другого бойца. Пришельцы, гражданские, танки и взятые под пси-контроль
пришельцы не защищены. Солдат XCOM остаётся защищённым, если пришелец временно
взял его под контроль, поскольку проверяется исходная сторона бойца.

Режим задаётся только параметром командной строки и не записывается в файл
настроек или сохранение. Для обычного запуска не указывайте `--god`.
